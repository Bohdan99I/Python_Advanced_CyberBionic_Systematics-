## Завдання 1: Створення бази даних "University"

### 📘 Мета
Створити базу даних **university**, яка містить три таблиці:
- **students** — інформація про студентів;
- **groups** — інформація про навчальні групи;
- **grades** — оцінки студентів з предметів.

База даних має зберігати дані про студентів, групи та їх оцінки.

### 🧩 Структура таблиць

#### Таблиця `students`
| Поле | Тип | Опис |
|------|-----|------|
| id | INTEGER | Ідентифікатор студента (PRIMARY KEY) |
| firstname | TEXT | Ім'я студента |
| lastname | TEXT | Прізвище студента |
| group_id | INTEGER | Ідентифікатор групи (FOREIGN KEY на таблицю `groups`) |

---

#### Таблиця `groups`
| Поле | Тип | Опис |
|------|-----|------|
| id | INTEGER | Ідентифікатор групи (PRIMARY KEY) |
| name | TEXT | Назва групи (наприклад, CS-101) |
| faculty | TEXT | Назва факультету |

---

#### Таблиця `grades`
| Поле | Тип | Опис |
|------|-----|------|
| student_id | INTEGER | Ідентифікатор студента (FOREIGN KEY на таблицю `students`) |
| subject | TEXT | Назва предмету |
| grade | INTEGER | Оцінка за предмет |
| date | TEXT | Дата отримання оцінки |
