## Завдання 2
Програма збирає дані з сайту [http://books.toscrape.com/](http://books.toscrape.com/)

## Дані для кожної книги:
- Назва книги  
- Ціна (у фунтах стерлінгів)  
- Рейтинг (наприклад: One, Two, Three, Four, Five)  
- Наявність (перевірка, чи є текст "In stock")  

## Збереження результатів:
- Дані зберігаються у файл `books_data.csv`  
- Заголовки стовпців: **Назва, Ціна, Рейтинг, Наявність**

### Приклад:
```
Назва,Ціна,Рейтинг,Наявність
A Light in the Attic,51.77,Three,True
Tipping the Velvet,53.74,One,True
The Secret Garden,15.00,Two,True
```

## Використані бібліотеки:
- requests  
- beautifulsoup4  
- pandas (для запису у CSV або Excel)

## Запуск:
1. Встановити бібліотеки:
   ```bash
   pip install requests beautifulsoup4 pandas
   ```
2. Запустити файл:
   ```bash
   python main.py
   ```
3. Результат буде у файлі `books_data.csv`
